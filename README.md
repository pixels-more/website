# Pixels & More – Website

Statische Website unter **https://pixelsandmore.de**, ausgeliefert über GitHub Pages aus `main`.
Startseite, Datenschutzerklärung für alle Apps, Impressum; jeweils Deutsch und Englisch (`en/`).

## Regeln

- **Nur statisches HTML und CSS.** Kein Build-Schritt, kein Framework, kein JavaScript nötig.
- **Keine externen Ressourcen:** keine Web-Schriften, keine CDNs, keine Einbettungen, keine
  Cookies, keine Analyse. Grund: Das Versprechen „Kein Tracking“ gilt auch für die Website, und
  jede fremde Ressource würde Besucherdaten an Dritte geben.
- **Die Datenschutzerklärung gilt für alle Apps der Suite.** Erhebt eine App künftig doch Daten
  (z. B. Käufe mit eigener Verarbeitung), wird sie hier vor dem Release ergänzt.
- **Unveröffentlichte Projekte stehen nicht auf der Seite.** Grund: Namen und Ideen sind noch
  nicht geschützt, und die Seite soll nichts versprechen, was es noch nicht gibt.
- Das Repo ist öffentlich, weil GitHub Pages bei privaten Repos einen bezahlten Plan braucht.
  Hier liegt nichts, was nicht ohnehin auf der Website steht.

## Domain

`CNAME` enthält `pixelsandmore.de`. Die Domain liegt bei Strato; die DNS-Einträge dort zeigen
auf GitHub Pages.
